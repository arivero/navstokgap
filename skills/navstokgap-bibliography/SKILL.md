# Bibliography as research input

Bring one or two useful constructions from the bibliography into the active
task, with a concrete test toward the positive-action target. This is a
context-loading skill; AGENTS.md supplies the restart hook. A skill file alone
does not schedule execution or detect resets.

Resolve the repository from AGENTS.md or this skill's real path (two directories
above its directory). After selecting the task from the live restart state:

1. Read the relevant card in [the idea bridge index](../../references/IDEA_BRIDGES.md).
   Choose a second card only when it supplies a complementary mechanism or
   countertest. Prioritize the current proof obligation over broad similarity.
2. Read each selected source companion, including its coverage and remaining
   access gaps. Follow the linked model note when doing mathematical work.
   A source title or a remembered formula is a discovery lead until verified.
3. Put a compact working capsule in context: **source and passage → borrowed
   construction → proposed task test → premise/limit that decides the result**.
   Distinguish the source's statement from the repository's inference.
4. Continue the assigned task. Save useful new connections in its handoff;
   update the index only when the connection changes a future research decision.

Fresh source workers apply this within their assigned source and page budget;
they may use a supplied companion instead of opening an unrelated card. They
return one source-to-model suggestion in their handoff. The coordinator owns
shared index updates and claim acceptance.

## Cost and evidence

Use local companions on restart. Launch web research or a librarian only for a
specific missing passage or audit within the active task's authorization and
budget. Reuse a capsule retained in a compaction summary when its task and
sources remain current; reread when the capsule is absent or the task changes.

Idea ingestion and prior-art auditing have different outputs. The former
suggests a premise or construction; the latter records source matches and
bounded search coverage for each mathematical result. Preserve proof status and
literature status separately. The single-worker protocol remains in force.

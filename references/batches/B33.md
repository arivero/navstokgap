# B33: classical cut-state audit (R03)

## Result

The R03 note's central conclusion is supported as a finite-dimensional derived
calculation: for the fixed-energy harmonic receiver, retaining `(q,p)` restores
the Hamiltonian composition law, while projection to `q` followed by the
stationary conditional reset inserts `L P_#` and generally changes the law.
The missing interface datum is momentum (units `M L/T`), and the retained
block's coefficient supplies the compensating time/mass units. This closure
argument does not select a positive universal action.

The action statement is also a derived consequence of the explicitly fixed
ellipse: `J=(2 pi)^(-1)\oint p dq=E/omega`, with units `M L^2/T`, and it tends
to zero as `E` tends to zero at fixed Hamiltonian. The covariance determinant
has the same value under the stated uniform phase preparation. The note must
keep this normalization separate from A15's twice-area convention.

## Claim classification and issues

| Note claim | Classification | Audit result |
|---|---|---|
| Full `(q,p)` evolution composes exactly; position projection with `L P_#` inserts a reset | derived consequence | Follows directly from the Hamiltonian flow and conditional-law definitions. FKM's matrix propagator is a compatible established ingredient, not proof of the reset calculation. |
| Position-only conditional kernel has nonsemigroup conditional mean | derived consequence | The displayed block identity and `-q sin(omega s) sin(omega t)` defect are correct under the fixed-energy phase law. State explicitly that `K_t` is a stationary conditional kernel, not the transition kernel of a Markov state process. |
| Independent resets converge terminally to the starting position in conditional `L^2` | derived consequence | The stated cosine-power recurrences support this at fixed `T,E,k,m,M,q`; it is a terminal-observable limit only. Do not promote it to path-topology convergence or to a statement about observational cuts. |
| Two successive positions can reconstruct momentum | derived consequence | Correct when `sin(omega delta) != 0`; retain the half-period singularity and the finite-precision sensitivity qualification. Turning points require the phase-state convention. |
| `(q,p)` is the phase-state restoration | derived consequence/model choice | Exact for the fixed oscillator experiment. It is not a universal claim about all receivers; Zwanzig shows that eliminating bath variables can require a history-dependent memory term. |
| `J=E/omega` and `sqrt(det Cov(q,p))=E/omega` | derived consequence | Correct for the stated uniform phase and `1/(2 pi)` canonical normalization. Add the preparation dependence and distinguish this from A15's estimator before any cross-note comparison. |
| FKM harmonic propagator and Zwanzig memory construction | established ingredient | Supported only at the named passages and their hypotheses. FKM's infinite-chain/Markov route and Zwanzig's reduction do not establish a positive action scale, universality, or the note's reset limit. |

The most material issue is scope: “retaining momentum restores exact composition”
is proven for the closed two-body oscillator. In a receiver with eliminated
degrees of freedom, retaining tagged momentum may still leave a memory kernel;
the next model must distinguish omitted tagged velocity from eliminated bath
history. Also state whether `L` is the stationary conditional law at every
interface; otherwise the reset interpretation is underspecified.

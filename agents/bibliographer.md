# Bibliography worker (Luna preferred)

Read the assigned programme question and `agents/PROTOCOL.md`. Search primary
sources online, including arXiv where appropriate. Start with at most three query
families and return at most the assigned number of candidates. Prefer foundational
sources plus one later critical comparison, not an unranked list of recent claims.

For each candidate record verified title/authors/year, versioned arXiv ID or DOI,
open URL, abstract/passage coverage, relevance, and which project claim it cannot
establish. Do not claim novelty, reconstruct proofs or infer a theorem from its
title. Flag withdrawn, superseded or access-limited material when verified.

Write the assigned `references/batches/<id>.md` and source-facing companions under
the assigned `docs/batches/<id>/` directory for substantially used sources. Optional
candidate BibTeX stays in that batch; do not edit `references/library.bib`.
Downloading entire corpora is outside a minor search task. Stop with a useful
ranked reading queue and the standard handoff.

Manuscripts and generated papers

The PDF catalog classifies every retained PDF. The public Papers page renders that catalog; the argument catalog locates maintained science. Generated papers for superseded notes have been removed after consolidation. Their former note pages redirect to canonical arguments. Git preserves earlier source and artifact versions.

Build only a changed note with make paper NOTE=<slug>. Compilation and extracted-text checks establish document integrity, not independent proof review. Retired internal score reports and programme snapshots are preserved only in git history.

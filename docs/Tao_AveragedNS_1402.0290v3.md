# Finite time blowup for an averaged three-dimensional Navier–Stokes equation

> Source: [arXiv:1402.0290v3](https://arxiv.org/abs/1402.0290v3); [local PDF](Tao_AveragedNS_1402.0290v3.pdf).
> Metadata: Terence Tao; first submitted 2014, version 3 dated 2015-04-01.
> Extraction: `pdftotext -layout`; selective reading notes. Downloaded 2026-09-05.

## Source digest

Cited result: a modified, averaged nonlinearity preserves the energy cancellation yet permits finite-time blowup. This is not blowup for the original Navier–Stokes equation.

## Source-facing notes

Use the introduction and main averaged-equation theorem to test arguments that invoke only cancellation and coarse bounds. The averaging class matters: do not turn this result into a claim that every energy method must fail. Version 3 includes dilations in the averaging as well as rotations and multipliers.

## Source-to-model mapping

Theurel pp. 5--7 supplies a conditional impulsive Hamiltonian measurement with a thermal ready state and pointer momentum readable after interaction. It lacks the R06 premises of a finite-duration autonomous clock, fixed apparatus mass, bounded coupling/force, and explicit exact-record cost. Its quality parameter can be reduced by cooling or trap tightening, so it does not close the draft's zero-infimum counterexample.

Hermann--Krener p. 733 supplies a sufficient rank-condition observability theorem for smooth systems. The reference receiver's analytic output and derivative rank imply that four evaluation rows can be independent; positive-width pulse integration preserves this independence by determinant continuity. This is a project derivation, not a theorem citation for the exact pulse matrix.

## Source digest

The authors explicitly add an exact uncertainty premise: random momentum
fluctuations scale inversely with position uncertainty. Under homogeneity,
independence and causality assumptions they obtain a positive universal
constant `C` in the ensemble Lagrangian, then set `C=(hbar/2)^2` to identify the
Schrodinger equation (PDF pp. 5, 8). This is a reconstruction premise and a
useful next model test, not evidence that the A01 transport plateau is universal.

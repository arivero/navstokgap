# Runge–Kutta methods and renormalization

Brouder identifies the rooted-tree algebra shared by B-series composition and
Kreimer's renormalisation framework, and applies it to a field-theory toy model.

- Author: Christian Brouder; arXiv:hep-th/9904014v1, submitted 2 April 1999.
- [Primary record](https://arxiv.org/abs/hep-th/9904014v1),
  [PDF](https://arxiv.org/pdf/hep-th/9904014v1).
- Coverage: abstract, introduction and §§3–4.2 (printed pp. 1, 3–6) read
  2026-09-06/07; §6 is a further reading target. PDF text extraction.
- Anchors: §3, elementary differentials; §4.1, B-series; §4.2, character
  convolution and composition. Tree glyphs in the extraction need visual
  checking before individual tree formulae are transcribed.
- Rights: arXiv link; any downloaded research copy stays in ignored `.build/`.

## Use in this project

This is the precise algebraic bridge to Connes–Kreimer. It suggests how to
organise nonlinear composition corrections after the exact Gaussian test;
identifying an algebra does not determine its physical representation or scale.

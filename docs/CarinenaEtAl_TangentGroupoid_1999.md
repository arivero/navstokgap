# Connes' tangent groupoid and strict quantization

The authors construct a strict quantization on cotangent bundles of oriented
Riemannian manifolds using the tangent groupoid.

- Authors: José F. Cariñena, Jesús Clemente-Gallardo, Eduardo Follana,
  José M. Gracia-Bondía, Alejandro Rivero and Joseph C. Várilly.
- Version: [arXiv:math/9802102v3](https://arxiv.org/abs/math/9802102v3),
  2 February 1999; first submission 1998. Journal of Geometry and Physics
  32 (1999), 79–96; DOI 10.1016/S0393-0440(98)00028-X.
- [Primary PDF](https://arxiv.org/pdf/math/9802102v3).
- Coverage: abstract and introduction, §1.2 and opening §1.3, printed pp. 1–4,
  read 2026-09-07. Added selected passages in §§3.1–3.3, printed pp. 15–19,
  read 2026-10-30: deformation conditions, half-density convolution, Fourier
  boundary algebra and quantization maps/Jacobian. The curved construction
  and all imported proofs have not been audited in full.
- Reading status: source-reported quantization theorem, not project proof-audited.
- Rights: arXiv link; any downloaded research copy stays in ignored `.build/`.

## Use in this project

This supplies the established deformation framework used in the
[maintained scaling and state argument](../notes/groupoid-quantum-newton-states.md).
The flat scalar calculation there specifies the Hamiltonian and normalization;
its heat boundary is a semiclassical symbol. It does not identify an ordinary
principal symbol of a fixed operator with the full interacting dynamics,
or select a dimensionful physical action scale.

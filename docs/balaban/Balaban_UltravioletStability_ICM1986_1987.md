# Ultraviolet Stability Problems in Quantum Field Theories

Balaban’s overview explains a gauge-covariant block-spin construction and gives a three-dimensional ultraviolet-stability statement. It is a useful short primary introduction to the longer journal series.

## Interesting points

- Printed page 1260 defines a finite Wilson lattice integral with group-valued bond variables and Haar measure. This supplies an actual finite-dimensional starting object.
- Printed page 1261, equations (9)–(11), defines the coarse density by integrating over fine fields at fixed block average. The total integral is preserved and gauge-invariant densities remain gauge invariant.
- The same page makes the main object of the method the detailed inductive description of successive effective densities. The displayed stability bound is an application of that structure.
- The small/large-field decomposition partitions field space rather than deleting configurations. Printed pages 1261–1262 state the three-dimensional bound and describe the then-partial four-dimensional result.

Project connection (inference): our insertion question asks for this kind of controlled coarse density. The overview does not complete a continuum reconstruction or establish a physical spectral gap. Its four-dimensional status is historical to the 1986 talk; it does not describe the later 1987–1989 papers.

# Manuscripts and generated papers

The [PDF catalog](pdf-catalog.json) classifies every retained PDF. The
[public Papers page](../docs/papers.html) renders that catalog; the
[argument catalog](../notes/index.md) locates maintained science.
Generated papers for superseded notes have been removed after consolidation.
Their former note pages redirect to canonical arguments. Git preserves earlier
source and artifact versions.

Build only a changed note with `make paper NOTE=<slug>`. Compilation and
extracted-text checks establish document integrity, not independent proof review.
Historical/internal model scores are dated source evidence, not current verdicts.
